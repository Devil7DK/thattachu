# Thattachu

Offline Thanglish-to-Tamil transliteration for VS Code.

## Features

Select text and run **Thattachu: Transliterate** (`Ctrl+Shift+Alt+T`).

For automatic transliteration, run **Thattachu: Toggle Automatic
Transliteration** from the Command Palette. With it enabled, a completed
romanized word is converted when you type a space or punctuation mark. For
example, `vanakkam ` becomes `வணக்கம் `.

The bottom status bar shows the active typing mode (`English` or `Tamil`).
Click it, or press `Ctrl+Alt+M` while the editor is focused, to switch modes.

## Extension Settings

This extension contributes the following setting:

For example:

- `thattachu.autoTransliterate`: Enable/disable automatic transliteration. It
  defaults to `false`.
